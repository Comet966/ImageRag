# 拾图 Android 开发版

这是独立原生安卓应用，使用与桌面版相同的 `qwen3-vl-embedding` 模型和图片/文字余弦检索。Android 8.0 及以上；Android 13/14 的图库权限按系统授权范围读取。

在 Android Studio 中打开 `android/`，使用 Android SDK 37 和 Gradle 构建并安装 debug 版。打开应用，在「配置 API Key」中输入自己的阿里云 DashScope Key，点击「选择图库」并授权图片访问，选定相册后点击「建立索引」，完成后输入文字搜索。点击结果可通过系统图片应用打开原图。

- 图片按比例缩小并编码为 JPEG 后发送到阿里云接口进行向量化；每张图片各一次请求，可能产生费用并消耗流量。文本搜索也会调用接口。不会在启动时自动请求。
- 向量保存在应用私有 SQLite 中；密钥使用 Android Keystore 加密保存，不包含在应用备份中。卸载应用会删除本地索引和密钥。
- 再次扫描会跳过媒体 ID 和修改时间均未变化的图片；单张图片解码失败可下次重试。索引保留期间，需重新授权才能展示图片。已删除或无法访问的图片不会出现在搜索结果中。
- 当前索引在应用进程内运行，保持应用打开；中途退出可能中断，重新扫描可继续。暂无后台任务、删除失效索引、查询缓存和 OCR。相似度不是匹配概率。
- 此开发版直接由设备连接阿里云北京地域接口；请只配置自己的密钥，勿把密钥写入源码或分享 APK 时预置密钥。

设置中可修改完整的 HTTPS 多模态向量 API 请求地址；默认地址为北京地域 DashScope 接口。自定义服务需兼容现有请求和响应格式，应用会将图片、搜索文字和 API Key 发往该地址，请使用可信服务。不同地址使用独立索引，切换地址后需要重新扫描；切回原地址可继续使用原索引。

点击「选择图库」可多选系统可访问的相册，确认后再点击「建立索引」。索引和搜索仅处理当前所选相册内、且系统授权访问的图片；再次扫描会处理所选相册中新加入的图片。取消选择不会删除已有向量，重新选中后可以继续使用。首页显示的累计索引数量包括当前服务地址下以前索引过的其他相册。此版本按相册选择，不支持逐张挑选。
